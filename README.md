# TicTacToe Game

A simple TicTacToe game built with Java and Swing GUI.

## How to Run
cd src
javac model/*.java controller/*.java view/*.java
java view.TicTacToeGUI

## Game Modes
- vs AI 
- 2 Player mode

## Project Structure
src/model      -  game data classes
src/controller -  game logic
src/view       -  GUI window

## OOP Used
-  Encapsulation
-  Abstraction
-  Inheritance
-  Polymorphism
